# latted-ui

Concept rebuild of Latted by Yusuf Choudhury, for a GTM internship application. Not affiliated with Latted.

All visuals are CSS and SVG, plus a text wordmark. No assets copied from the live site. Fonts: Geist (OFL) via @fontsource.

Routes:

- `/` is a close 1:1 rebuild of Latted's live site.
- `/upgraded` is the same site with Yusuf's growth ideas built in.
- `/for-latted` is a walkthrough of those changes, linking to both.

Every route is set to `noindex`. `npm i && npm run dev`.
